# RD Catalog Web — read-only LAN monitor

Браузерный монитор **Комплекты** и **АН** (остальные вкладки Qt в WEB нет).
Данные собирает `rd_catalog/monitor_views.py` с `sheets=WEB_MONITOR_SHEETS`.
Этот пакет **только читает** локальный SQLite и JSON-кэши. Скан, Google, Outlook,
робот, пины и записи журнала — только в Qt.

## Запуск

Из корня репозитория, **на той же машине**, где открыт Qt-каталог:

```bat
pip install fastapi uvicorn
python -m rd_catalog_web --host 0.0.0.0 --port 8765
```

Опции: `--host`, `--port`, `--config путь.json` (override для `load_config`).

`0.0.0.0` в `--host` — это bind на все сетевые карты, **не** адрес для браузера.
В консоли печатаются URL:

- `http://127.0.0.1:8765` — этот ПК
- `http://<LAN-IP>:8765` — другие машины в локальной сети

Из Qt-каталога: галка **Автозапуск WEB** (при открытии окна, без браузера), кнопка **Открыть WEB** (старт + браузер на `127.0.0.1`) и **Ссылка для коллег** (копирует `http://<LAN-IP>:8765`). Подпись справа — тот же LAN-адрес. Скан при этом не блокируется.

Порядок и ширины колонок **Комплекты** — тот же `kits_table_layout.json`, что GUI (runtime, иначе заводской файл рядом с `rd_catalog/kits_table_layout.py`). Чтобы WEB совпал с тем, что вы расставили в Qt, нажмите **Сохранить шаблон колонок**. Кнопка **Сохранить Excel** на Комплектах скачивает видимые строки текущего фильтра/сортировки; заливка та же, что на экране.

SQLite — локальный файл `%LOCALAPPDATA%\Documentation_PDF_out_NK\rd_catalog\rd_catalog.sqlite`,
**не** UNC/SMB. Конфиг по умолчанию тот же, что у Qt.

Авторизации нет. Не пробрасывайте порт в интернет и не вешайте сервер на
публичный интерфейс за пределами LAN.

## Брандмауэр Windows

Коллегам нужен IP **Ethernet/Wi-Fi этого ПК**, не VPN (адаптеры вроде OpenVPN,
«Amsterdam», Tailscale). Кнопка **Ссылка для коллег** копирует не-VPN адрес.

Входящий TCP 8765 должен быть разрешён. На доменном ПК GPO часто ставит
**BlockInbound** и отключает локальные правила (`LocalFirewallRules` = только GPO).
Тогда `netsh advfirewall ... add rule` **не поможет** — нужен inbound-исключение
в политике IT.

Если локальные правила ещё действуют (запуск от администратора):

```bat
netsh advfirewall firewall add rule name="RD Catalog Web" dir=in action=allow protocol=TCP localport=8765
```

Правило не нужно, если смотрите только с `127.0.0.1` на этом ПК.

## Что есть в WEB

Комплекты (с карточкой) и АН. Ревизии MTO, перечень, готовность, журнал выдачи
и коллизии смотрите в Qt.

Обновить данные: кнопка **Обновить** (`?refresh=1`) или `POST /api/refresh`.
Кэш также сбрасывается, когда меняется mtime sqlite (включая WAL).

Таблицы: Tabulator 6 лежит в `rd_catalog_web/static/vendor/` (без CDN).
Навигация: `?tab=kits&title=9110&mark=KSB` или `?tab=an&...`. Контекстное меню
копирует UNC-путь в буфер; сервер файлы не открывает.

Первый запрос `/api/meta` + `/api/kits` собирает Комплекты и АН из SQLite
(без heatmap/журнала) — на большой базе это всё равно несколько секунд.
Дальше кэш, пока не сменится mtime sqlite или кнопка **Обновить**.
